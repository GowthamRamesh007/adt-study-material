Define Abstract Data Type (ADT) with any one example.
▼

Answer:

Abstract Data Type (ADT) is a mathematical model that defines a data type by its behavior from the user's point of view, specifically what operations can be performed on the data and what results those operations produce, without specifying how these operations are implemented.

Key Characteristics:

  • Data Abstraction: Hides internal implementation details
  • Encapsulation: Bundles data with operations that manipulate it
  • Information Hiding: Only the interface is visible, implementation is hidden

Example: Stack ADT

Stack is an ADT that follows LIFO (Last-In-First-Out) principle.

Operations:
  • push(element) - Insert element at top
  • pop() - Remove and return top element
  • peek() - View top element without removing
  • isEmpty() - Check if stack is empty
  • isFull() - Check if stack is full
Stack Example: Push(10) → [10] Push(20) → [20][10] Push(30) → [30][20][10] ← Top Pop() → Returns 30, Stack: [20][10]

The user doesn't need to know whether the stack is implemented using arrays, linked lists, or any other structure. They only use the defined operations.

Real-world analogy: Stack of plates - you can only add or remove from the top!

What is a circular linked list? Mention its advantage over singly linked list.
▼

Answer:

Circular Linked List is a variation of linked list where the last node points back to the first node instead of NULL, forming a circular structure.

Singly Linked List: [10] → [20] → [30] → [40] → NULL Circular Linked List: [10] → [20] → [30] → [40] ──┐ ↑ │ └────────────────────────────┘

Advantages over Singly Linked List:

FeatureSingly LinkedCircular Linked
Reaching first from lastO(n) - traverse entire listO(1) - direct access via last→next
Continuous traversalNot possible (ends at NULL)Possible (loops infinitely)
Insert at endO(n) without tail pointerO(1) with tail pointer
Insert at beginningO(1)O(1) even simpler
Key Advantages:
  • No NULL pointers - every node has a valid next
  • Can traverse entire list starting from any node
  • Perfect for round-robin scheduling (CPU scheduling, multiplayer games)
  • Easy implementation of circular queues
Applications: Round-robin CPU scheduling, multiplayer game turns, music playlist repeat mode, token ring networks

▼

(i) Full Binary Tree:

A tree where every node has either 0 or 2 children. No node has exactly one child.

Full Binary Tree: 1 / \ 2 3 / \ / \ 4 5 6 7 All nodes: 0 or 2 children ✓

(ii) Complete Binary Tree:

A tree where all levels are completely filled except possibly the last, which is filled from left to right.

Complete Binary Tree: 1 / \ 2 3 / \ / 4 5 6 Last level filled left→right ✓

What is an AVL tree? What is the condition for a tree to be an AVL tree?
▼

Answer:

AVL Tree (Adelson-Velsky and Landis) is a self-balancing binary search tree where the height difference between left and right subtrees is at most 1 for every node.

Condition for AVL Tree:

Balance Factor (BF) = Height(Left Subtree) - Height(Right Subtree)
AVL Condition: |BF| ≤ 1 for EVERY node
Valid BF values: -1, 0, +1
AVL Tree (Valid): 50 (BF=0) / \ 30(0) 70(BF=-1) / \ \ 20 40 80(0) All |BF| ≤ 1 ✓ NOT AVL (Invalid): 50 (BF=-2) \ 70 (BF=-1) \ 80 Node 50: |BF|=2 ✗

Rotation Types:

CaseRotation
BF=+2, Left child BF=+1LL Rotation (Right rotate)
BF=-2, Right child BF=-1RR Rotation (Left rotate)
BF=+2, Left child BF=-1LR Rotation (Left-Right)
BF=-2, Right child BF=+1RL Rotation (Right-Left)
Advantages: Guaranteed O(log n) for search, insert, delete. No worst-case O(n) like regular BST!

▼

Define height and depth of a binary tree.
▼

Height:

Number of edges from a node to the deepest leaf (calculated bottom-up).

  • Height of leaf node = 0
  • Height of tree = Height of root

Depth:

Number of edges from root to that node (calculated top-down).

  • Depth of root = 0
  • Also called "Level"

What is a priority queue? Give one real-time application.
▼

Answer:

Priority Queue is an ADT where each element has a priority, and elements are served based on priority (not insertion order).

Types:

  • Max Priority Queue: Highest priority served first
  • Min Priority Queue: Lowest priority served first

Operations:

OperationTime (Heap)
insert(element, priority)O(log n)
extractMax/Min()O(log n)
peek()O(1)
Real Application: Hospital Emergency Room
  • Patients arrive with different severity levels
  • Critical patients (Priority 10) treated before minor injuries (Priority 2)
  • Not first-come-first-served, but priority-based
  • Saves lives by treating urgent cases immediately
Other Applications: CPU scheduling, Dijkstra's algorithm, Huffman coding, load balancing

Convert infix to postfix and evaluate postfix expression using stack
▼

Complete C Program:

#include <stdio.h> #include <stdlib.h> #include <string.h> #include <ctype.h> #define MAX 100 // Stack for operators char stack[MAX]; int top = -1; void push(char c) { stack[++top] = c; } char pop() { return stack[top--]; } char peek() { return stack[top]; } int isEmpty() { return top == -1; } // Precedence function int precedence(char op) { if (op == '+' || op == '-') return 1; if (op == '*' || op == '/') return 2; return 0; } // Convert infix to postfix void infixToPostfix(char* infix, char* postfix) { int i = 0, j = 0; while (infix[i] != '\0') { // If operand, add to postfix if (isalnum(infix[i])) { postfix[j++] = infix[i]; } // If '(', push to stack else if (infix[i] == '(') { push(infix[i]); } // If ')', pop until '(' else if (infix[i] == ')') { while (!isEmpty() && peek() != '(') { postfix[j++] = pop(); } pop(); // Remove '(' } // Operator else { while (!isEmpty() && precedence(peek()) >= precedence(infix[i])) { postfix[j++] = pop(); } push(infix[i]); } i++; } // Pop remaining operators while (!isEmpty()) { postfix[j++] = pop(); } postfix[j] = '\0'; } // Stack for evaluation int evalStack[MAX]; int evalTop = -1; void pushEval(int val) { evalStack[++evalTop] = val; } int popEval() { return evalStack[evalTop--]; } // Evaluate postfix int evaluatePostfix(char* postfix) { int i = 0; while (postfix[i] != '\0') { if (isdigit(postfix[i])) { pushEval(postfix[i] - '0'); } else { int val2 = popEval(); int val1 = popEval(); switch(postfix[i]) { case '+': pushEval(val1 + val2); break; case '-': pushEval(val1 - val2); break; case '*': pushEval(val1 * val2); break; case '/': pushEval(val1 / val2); break; } } i++; } return popEval(); } int main() { char infix[] = "(5+3)*2-8/4"; char postfix[MAX]; printf("Infix: %s\n", infix); infixToPostfix(infix, postfix); printf("Postfix: %s\n", postfix); int result = evaluatePostfix(postfix); printf("Result: %d\n", result); return 0; }

Circular queue using arrays: Enqueue, Dequeue, Display, isEmpty, isFull
▼

Complete C Program:

#include <stdio.h> #define SIZE 5 int queue[SIZE]; int front = -1, rear = -1; // Check if full int isFull() { return ((rear + 1) % SIZE == front); } // Check if empty int isEmpty() { return (front == -1); } // Enqueue void enqueue(int data) { if (isFull()) { printf("Queue is Full!\n"); return; } if (front == -1) // First element front = 0; rear = (rear + 1) % SIZE; queue[rear] = data; printf("Inserted %d\n", data); } // Dequeue int dequeue() { if (isEmpty()) { printf("Queue is Empty!\n"); return -1; } int data = queue[front]; if (front == rear) { // Last element front = rear = -1; } else { front = (front + 1) % SIZE; } printf("Deleted %d\n", data); return data; } // Display void display() { if (isEmpty()) { printf("Queue is Empty!\n"); return; } printf("Queue: "); int i = front; while (1) { printf("%d ", queue[i]); if (i == rear) break; i = (i + 1) % SIZE; } printf("\n"); } int main() { enqueue(10); enqueue(20); enqueue(30); enqueue(40); display(); // 10 20 30 40 dequeue(); // Remove 10 dequeue(); // Remove 20 display(); // 30 40 enqueue(50); // Wraps around enqueue(60); // Wraps around display(); // 30 40 50 60 return 0; }

How Circular Queue Works:

Initial: front=-1, rear=-1 [ ][ ][ ][ ][ ] After enqueue(10,20,30): front=0 rear=2 [10][20][30][ ][ ] After dequeue() twice: front=2 rear=2 [ ][ ][30][ ][ ] After enqueue(40,50,60): front=2 [50][60][30][40][ ] ↑ ↑ front rear Wraps around! No space wasted!
Advantages over Linear Queue:
  • No space wastage - reuses freed positions
  • Efficient memory utilization
  • Continuous operation without reset

Formulas:

isEmpty: front == -1 isFull: (rear + 1) % SIZE == front Enqueue: rear = (rear + 1) % SIZE Dequeue: front = (front + 1) % SIZE

Design task management system with priority queue: addTask, removeHighestPriority, viewPending, countTasks
▼

Complete Implementation:

1. ADT Specification (3 marks):

Data Structure:
  • Task Name (string)
  • Priority (integer: 1=Low, 2=Medium, 3=High)
  • Next pointer
Operations:
  • addTask(name, priority) - Insert maintaining priority order
  • removeHighestPriority() - Delete from front (highest priority)
  • viewPendingTasks() - Display all tasks
  • countTasks() - Return total count

2. Justification (2 marks):

I chose priority-based sorted linked list because:
  • Insertion maintains priority order: O(n)
  • Removal of highest priority: O(1) from front
  • No fixed size limitation (dynamic)
  • Easy to implement under exam conditions

3. Complete C Implementation (8 marks):

#include <stdio.h> #include <stdlib.h> #include <string.h> struct Task { char name[50]; int priority; // 3=High, 2=Medium, 1=Low struct Task* next; }; struct Task* head = NULL; // Add task (sorted by priority) void addTask(char name[], int priority) { struct Task* newTask = (struct Task*)malloc(sizeof(struct Task)); strcpy(newTask→name, name); newTask→priority = priority; newTask→next = NULL; // Insert at beginning if higher priority if (head == NULL || head→priority < priority) { newTask→next = head; head = newTask; printf("Added: %s (Priority: %d)\n", name, priority); return; } // Find correct position struct Task* temp = head; while (temp→next != NULL && temp→next→priority >= priority) { temp = temp→next; } newTask→next = temp→next; temp→next = newTask; printf("Added: %s (Priority: %d)\n", name, priority); } // Remove highest priority task void removeHighestPriority() { if (head == NULL) { printf("No tasks to remove!\n"); return; } struct Task* temp = head; printf("Removed: %s (Priority: %d)\n", temp→name, temp→priority); head = head→next; free(temp); } // View all pending tasks void viewPendingTasks() { if (head == NULL) { printf("No pending tasks.\n"); return; } printf("\n=== PENDING TASKS ===\n"); printf("%-30s Priority\n", "Task Name"); printf("----------------------------------------\n"); struct Task* temp = head; int count = 1; while (temp != NULL) { char* prio = (temp→priority == 3) ? "High" : (temp→priority == 2) ? "Medium" : "Low"; printf("%d. %-27s %s (%d)\n", count++, temp→name, prio, temp→priority); temp = temp→next; } printf("========================================\n"); } // Count tasks int countTasks() { int count = 0; struct Task* temp = head; while (temp != NULL) { count++; temp = temp→next; } return count; } int main() { printf("=== TASK MANAGEMENT SYSTEM ===\n\n"); // Add tasks addTask("Fix Bug #123", 3); // High addTask("Code Review", 2); // Medium addTask("Update Documentation", 1); // Low addTask("Security Patch", 3); // High addTask("Write Unit Tests", 2); // Medium viewPendingTasks(); printf("\nTotal tasks: %d\n", countTasks()); printf("\n--- Removing highest priority ---\n"); removeHighestPriority(); viewPendingTasks(); printf("\nTotal tasks: %d\n", countTasks()); return 0; }
